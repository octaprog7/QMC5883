# MicroPython драйвер для геомагнитного датчика QMC5883L

# Подключение (Шина I2C)
Подключите линии VCC, GND, SDA и SCL модуля QMC5883L к соответствующим пинам вашей микроконтроллерной платы (ESP32, ESP8266, Raspberry Pi Pico, STM32 и др.) с установленной прошивкой MicroPython. 
*(Не забудьте проверить и при необходимости изменить номера пинов SCL и SDA в конструкторе I2C внутри файла `main.py` под вашу конкретную плату).*

# Питание
Напряжение питания модуля QMC5883L — строго **3.3 В**. 
Подача 5 В может привести к необратимому повреждению датчика!

# Загрузка и запуск
1. Прошейте вашу плату официальной прошивкой MicroPython.
2. Загрузите на устройство файлы проекта: `main.py`, `qmc5883mod.py` и директорию `sensor_pack_2` со всем её содержимым.
3. Откройте `main.py` в вашей IDE (например, Thonny IDE) и запустите скрипт.

# Калибровка датчика

## Зачем нужна калибровка?

Магнитометры подвержены влиянию внешних магнитных полей и металлических объектов, расположенных рядом с датчиком. Это создает так называемые **жесткие магнитные искажения (Hard Iron Distortions)**, которые смещают центр измерений и приводят к ошибкам в определении направления.

Калибровка позволяет:
- **Компенсировать смещения** (offsets) по осям X, Y, Z
- **Повысить точность** измерений до ±1°
- **Устранить влияние** печатной платы, корпуса и nearby компонентов

## Процедура калибровки

### Автоматическая калибровка

Модуль предоставляет интерактивный режим калибровки:

1. **Запустите скрипт** `main.py`
2. **Нажмите любую клавишу** когда появится запрос о калибровке
3. **Вращайте датчик** в течение 15 секунд:
   - Медленно вращайте устройство во всех направлениях
   - Описывайте в пространстве фигуру "восьмерка" или сферу
   - Убедитесь, что рядом нет магнитов, динамиков, моторов

4. **Получите результаты**:
```console
    =============================================
    РЕЗУЛЬТАТЫ КАЛИБРОВКИ (Смещения)
    =============================================
    Смещение по оси X (Offset X):  -0.5251 G
    Смещение по оси Y (Offset Y):  -0.4580 G
    Смещение по оси Z (Offset Z):  -0.3460 G
    =============================================
```

### Ручная калибровка

Если вы хотите выполнить калибровку программно:

```python

# Создание калибратора

# Сбор данных (в цикле, вращая датчик)
for i in range(100):
```

## Сохранение и загрузка калибровки

После успешной калибровки **сохраните вычисленные смещения** в энергонезависимую память (например, в файл `calibration.json` на flash-памяти микроконтроллера). Это позволит избежать необходимости вращать датчик при каждом включении устройства.

Весь цикл работы с калибровкой (загрузка, применение и сохранение) осуществляется централизованно через объект `HardIronCalibrator`.

### Пример сохранения и загрузки из файла:

```python
import json
from sensor_pack_2.geosensmod import HardIronCalibrator

# 1. ЗАГРУЗКА калибровки при старте программы
clbr = HardIronCalibrator()
try:
    with open('calibration.json', 'r') as f:
        data = json.load(f)
    
    # Восстанавливаем сохраненные смещения
    clbr.offset_x = data['x']
    clbr.offset_y = data['y']
    clbr.offset_z = data['z']
    clbr._is_calibrated = True  # Явно активируем режим применения калибровки
    print("Калибровка успешно загружена из файла.")
except OSError:
    print("Файл калибровки не найден. Будут использованы нулевые смещения.")

# ... далее в основном цикле измерений ...
raw_data = sensor.get_measurement_value(-1)

# 2. ПРИМЕНЕНИЕ калибровки к сырым данным (единый метод для всех случаев)
cal_data = clbr.apply(raw_data) 

# ... если была запущена процедура новой калибровки (вращение датчика) ...
# 3. СОХРАНЕНИЕ новых смещений в файл
offsets = {
    'x': clbr.offset_x,
    'y': clbr.offset_y,
    'z': clbr.offset_z
}
with open('calibration.json', 'w') as f:
    json.dump(offsets, f)
```
